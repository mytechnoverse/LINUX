Nftables

https://wiki.nftables.org/wiki-nftables/index.php/Load_balancing

Families : ip ( ipv4 ) , ip6 ( ipv6 ) , inet ( dual stack ) , bridge , arp ( ipv4 )

Traffic for every address family and hook is allowed unless there is a chain defined at that hook for a table with that address family .
priorities define ordering for chains in scope of a specifc hook .
Block fragmentation at Ingress hook to be able to use dport directive .

============================================================================================================

Router ARP Block :

=== IPv4 :

table arp chain type filter hook forward priority 0 policy drop

=== IPv6 :

table inet chain type filter hook forward priority 0
meta l4proto ipv6-icmp icmpv6 type { 135, 136 } drop

============================================================================================================

Router Ping :

table inet chain type filter hook forward priority 0

====== IPv4 :
--- Ping Req   : ip protocol icmp icmp type 8 { accept | drop }
--- Ping Reply : ip protocol icmp icmp type 0 { accept | drop }

====== IPv6 :
--- Ping Req    : meta l4proto ipv6-icmp icmpv6 type 128 { accept | drop }
--- Ping Resply : meta l4proto ipv6-icmp icmpv6 type 129 { accept | drop }

============================================================================================================

Router NAT :

table inet 

====== Destination ( Nginx Request ) :

type nat hook prerouting priority start at -100

--- IPv4 :
{ tcp | udp } dport { ORG PORT } dnat to { NATED ADDR }:{ NATED PORT }
--- IPv6 :
{ tcp | udp } dport { ORG PORT } dnat to [{ NATED ADDR }]:{ NATED PORT }

====== Source ( Nginx Response ) :

type nat hook postrouting priority start at 100 :

--- IPv4 :
ip daddr { NATED ADDR } { tcp | udp } dport { NATED PORT } snat to { ORG ADDR }
--- IPv6 :
ip6 daddr { NATED ADDR } { tcp | udp } dport { NATED PORT } snat to { ORG ADDR }

====== NAT Filtering :

type filter hook forward priority start at 0 :

ct state established,related accept

--- IPv4 :
ip daddr { NATED ADDR } { tcp | udp } dport { NATED PORT } accept
--- IPv6 :
ip6 daddr { NATED ADDR } { tcp | udp } dport { NATED PORT } accept

Direct Server Return ( DSR ) :

Nginx should have the Router IP on a loopback interface

No connection Tracking is done in DSR 


NAT Layer 3 Flow IP Addresses :

1. Client -> Router : src client , dst router
2. Router -> Server : src client , dst server ( DNAT )
3. Server -> Router : src server , dst router
4. Router -> Client : src router , dst client ( SNAT )
